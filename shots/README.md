# 手順のスクリーンショット

「スマートれん太での出し方」に表示される画像を置く場所。
ファイルが無ければ、その枠だけ「準備中」と出て手順の文章は残る。

| ファイル名 | 何を写すか |
| --- | --- |
| `menu.png` | 事務メニュー ＞ 売掛・買掛他 の中に「レンタル卸料金支払予定表」がある画面 |
| `cond.png` | 条件の入力画面（部門・年月・レンタル卸の欄が見える状態） |
| `excel.png` | 「Excelへ」ボタンの位置が分かる画面 |

## 置く前に必ず確認すること

**このリポジトリは公開されている。** 画像に次のものが写っていたら差し替えるか、その部分を塗りつぶすこと。

- 利用者名・お客様名・お客様番号
- 取引先名（仕入先名の一覧を含む）
- 金額の明細

条件の入力画面とメニュー画面であれば、通常これらは写らない。
**結果の一覧が出ている画面は使わない。**

PNG 推奨。横幅は 1200px 程度あれば十分で、それ以上は縮小してから置く。

## 追加のしかた

`.gitignore` で画像は既定で追跡しないようにしてある。
`git add -A` では入らないので、中身を確認したうえで明示的に追加すること。

```
git add -f shots/menu.png
```
