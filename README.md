# レンタル卸 金額不一致チェッカー

卸元から届く月次の請求データと、スマートれん太から出力した支払予定表を突き合わせて、
**金額が合わない利用者の一覧**を Excel で出すツール。

これまで700〜900行を目視で照合していた作業を、差異のある数十人の確認に置き換える。

## 使い方

1. スマートれん太の「レンタル卸支払予定表」を **部門・仕入先コードを空欄のまま**「Excelへ」で保存する
2. 卸元から届いた請求データ（CSV 推奨）を用意する
3. 画面に2つのファイルを入れる
4. 対象年月を確認する（卸元のデータに年月の列が無いため、目視確認が必須）
5. 「利用者の重なりから候補を出す」で対応表を作り、内容を確認する
6. 「突合する」→ 結果を確認して Excel をダウンロード

## つくり

| | |
|---|---|
| 形態 | GitHub Pages 上の静的サイト。サーバーを持たない |
| ビルド | 不要。`index.html` をそのまま配信する |
| 依存 | SheetJS 1本のみ。`vendor/` に同梱し、CDN からは読み込まない |
| データの扱い | **すべてブラウザ内で処理し、外部に送信しない**（CSP で通信を禁止） |
| 保存するもの | 設定のみ（`localStorage`）。業務データは保存しない |

```
index.html        画面
app.core.js       ファイル読み込みと正規化
app.match.js      名寄せ・明細の割当・バケット・検算
app.ui.js         画面まわりと Excel 出力
vendor/           同梱ライブラリ（出所とハッシュは vendor/README.md）
shots/            手順のスクリーンショット（置き方と注意は shots/README.md）
test.js           合成データによる自動テスト（node test.js）
DESIGN.md         設計書
```

画面の「スマートれん太での出し方」には出力手順を載せてある。
`shots/` に画像を置くと手順に差し込まれ、無ければその枠だけ「準備中」と出て文章は残る。
**画像を置く前に `shots/README.md` の注意を読むこと**（このリポジトリは公開されている）。

## 設計上の要点

詳しくは [DESIGN.md](./DESIGN.md)。特に効いているのは次の3つ。

**外部に出さない** — CDN 上のスクリプトは読み込んだファイルの中身にアクセスして送信できる。
そのためライブラリを同梱し、CSP で `connect-src 'none'` を宣言して通信そのものを禁止している。

**取りこぼしを検算で保証する** — 両ファイルの全行を排他的な5つのバケット
（金額不明／範囲外／除外／突合済み／片側のみ）に必ず1つだけ割り当て、
`全行の差 = 各バケットの差の合計` が成立することを画面に出す。成立しなければ実装に取りこぼしがある。

**「不一致なし」を軽々しく出さない** — 範囲外・金額不明・名寄せ要確認・明細未確定・
弱い根拠での名寄せが1件でも残っていれば「判定不能あり」と表示する。
一部だけ突合したのに全部やったように見える状態を防ぐ。

## 開発

```bash
node test.js                                  # 合成データのテスト
python -m http.server 8931 --bind 127.0.0.1   # ローカルで開く
```

実データを使う検証は `verify.local.js`（拠点名・仕入先コード・利用者名を含むため
`.gitignore` で除外。リポジトリには入れない）。

**このリポジトリには取引先名・仕入先コード・利用者情報を書かない。** 公開リポジトリのため。
拠点と部門×仕入先の対応表は、利用者が画面で登録して各自の端末に保存する。
